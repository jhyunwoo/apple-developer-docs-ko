# watchOS Release Notes

watchOS SDK의 변경 사항을 알아봅니다.

## 개요

Apple Developer Program은 Apple Watch용 App Store 앱을 빌드하고 배포하는 데 필요한 모든 것을 제공합니다. 멤버십에는 beta OS 릴리스 접근 권한, 고급 앱 기능, 앱과 Safari extension을 개발, 테스트, 배포하는 도구가 포함됩니다. 자세한 내용은 [Apple Developer Program](https://developer.apple.com/programs/)을 참고하십시오.

### 버그 보고

릴리스 노트에 언급되지 않은 문제는 [Feedback Assistant](https://developer.apple.com/bug-reporting/)를 통해 버그를 제출하십시오.
