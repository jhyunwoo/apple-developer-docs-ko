# Swift Playgrounds

Swift Playgrounds에서 앱 작성 방법을 배우고, 샘플 코드를 재활용하며, 학습 경험을 만들고 공유합니다.

## 개요

[Swift Playgrounds](https://www.apple.com/swift/playgrounds/)는 개발자가 탐색하고, 실험하고, 코딩과 앱 제작 방법을 배울 수 있는 독특한 환경을 제공합니다. 코딩이 처음인 사람에게 Swift Playgrounds는 Swift 프로그래밍 언어, SwiftUI, 그리고 Apple 플랫폼인 iOS, iPadOS, macOS용 앱을 만들 때 사용할 API(프레임워크)로 무엇이 가능한지 탐색할 수 있는 방법을 제공합니다. 숙련된 개발자에게 app playground는 iPad나 Mac의 Swift Playgrounds에서 직접 SwiftUI 앱을 작성하고 App Store에 제출할 수 있게 해 줍니다. 교육자라면 Swift Playgrounds를 활용해 학습자가 코드를 살펴보고, 이해하고, 상호 작용하도록 돕는 단계별 안내형 playground book을 만들 수 있습니다.

![Swift Playgrounds에서 완성된 Keep Going with Apps app playground 모습입니다. 앱에는 세 개의 세로 보기 영역이 있습니다. 왼쪽 열은 Project Navigator이며, 여기서 `ContentView` 파일이 선택된 Code 파일 목록을 보여 줍니다. 가운데 보기에는 `ContentView` 파일의 코드가 표시됩니다. 오른쪽 보기에는 `Make the Creatures Dance` 탐색 링크와 고릴라, 공작, 오징어 creature 목록 항목이 있는 My Creatures App 콘텐츠 view preview가 표시됩니다.](https://developer.apple.com)

다음 문서들은 한 단계 더 나아갈 준비가 되었을 때 app playground를 만들고 다듬는 데 도움을 줍니다. 이 문서들은 Swift Playgrounds에서 앱이나 book을 최대한 활용할 수 있도록 팁과 기법을 제공합니다. Swift Package를 추가해 Swift Playgrounds가 제공하는 콘텐츠나 다른 개발자의 콘텐츠로부터 앱 기능을 확장하는 방법을 배워 보십시오. preview 시스템, 앱 capability, 콘솔 디버깅을 활용하는 방법도 알 수 있습니다. app playground나 playground book을 완성하면 subscription으로 공유해 새로운 세대의 Swift 개발자에게 영감을 줄 수 있습니다.

## App playground
- [Adding a Swift package to your app playground](https://developer.apple.com/documentation/swift-playgrounds/add-a-swift-package): 공개적으로 제공되는 Swift package를 찾아 추가해 app playground의 기능을 확장합니다.
- [Debugging an App Playground using the Console](https://developer.apple.com/documentation/swift-playgrounds/console-print-debugging): 콘솔 출력을 사용해 코드를 디버그하는 여러 방법을 배웁니다.
- [Previewing SwiftUI views in Swift Playgrounds](https://developer.apple.com/documentation/swift-playgrounds/live-preview): Swift Playgrounds의 canvas를 사용해 앱 안 SwiftUI view의 실시간 preview를 확인합니다.
- [Requesting access to capabilities for your app playground](https://developer.apple.com/documentation/swift-playgrounds/project-capabilities): 센서 같은 보호된 리소스, 서비스, 또는 기기 하드웨어에 앱이 접근할 수 있도록 요청합니다.
- [Importing sample content into user app playgrounds](https://developer.apple.com/documentation/swift-playgrounds/using-content-in-user-projects): 샘플 코드를 app playground로 가져오는 방법을 배웁니다.
:::

## Subscription
- [Creating a subscription](https://developer.apple.com/documentation/swift-playgrounds/creating-a-subscription): 다른 사람이 다운로드할 수 있도록 playground book 집합의 기계 판독 가능한 요약을 만듭니다.
- [Localizing a Subscription Feed](https://developer.apple.com/documentation/swift-playgrounds/localizing-a-subscription-feed): 하나의 feed 안에서 subscription 콘텐츠의 여러 현지화를 제공합니다.
- [Publishing a Subscription](https://developer.apple.com/documentation/swift-playgrounds/publishing-a-subscription): 시리즈 안의 playground book을 온라인에서 다운로드하고 subscription할 수 있게 공개합니다.
:::
