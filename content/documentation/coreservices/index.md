# Core Services

실행 및 identity 서비스 같은 핵심 운영 체제 서비스에 접근하고 이를 관리합니다.

## 개요

이 문서 모음은 Carbon 애플리케이션에서 사용하는 여러 기본 운영 체제 서비스를 아우르는 Core Services 프레임워크의 API 레퍼런스를 제공합니다.

:::topic-grid
## 레퍼런스
- [Apple Events](https://developer.apple.com/documentation/coreservices/apple_events): 프로세스 경계를 넘어 메시지를 주고받으며, 수행하고 reply event로 응답할 수 있습니다.
- [Backup Core](https://developer.apple.com/documentation/coreservices/backup_core): macOS Backup 유틸리티가 사용하는 파일 및 폴더 설정의 저수준 세부 사항에 접근합니다.
- [Dictionary Services](https://developer.apple.com/documentation/coreservices/dictionary_services): 시스템 사전에서 단어와 구를 찾습니다.
- [File System Events](https://developer.apple.com/documentation/coreservices/file_system_events): 디렉터리 계층 구조의 내용이 변경될 때 알림을 받습니다.
- [Launch Services](https://developer.apple.com/documentation/coreservices/launch_services): 현재 앱 프로세스에서 다른 앱 안의 문서를 실행하고 엽니다.
- [File Metadata](https://developer.apple.com/documentation/coreservices/file_metadata): 파일 또는 파일 시스템의 일부인 데이터를 바탕으로 파일을 검색합니다.
- [OS Services](https://developer.apple.com/documentation/coreservices/os_services): 사용자 및 그룹 계정, 전원 관리 등을 포함한 운영 체제 서비스와 상호 작용합니다.
- [Search Kit](https://developer.apple.com/documentation/coreservices/search_kit): 자연어 문서를 색인화하고 검색합니다.
- [Carbon Core](https://developer.apple.com/documentation/coreservices/carbon_core): 레거시 기술과 상호 작용합니다.
- [Core Services Constants](https://developer.apple.com/documentation/coreservices/core_services_constants)
:::
