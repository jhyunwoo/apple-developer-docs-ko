# Xcode Release Notes

Xcode의 변경 사항을 알아봅니다.

## 개요

Xcode는 지능형 코드 완성, Apple 기기용 시뮬레이터, 고급 프로파일링 및 디버깅 도구 등을 포함해 모든 Apple 플랫폼용 앱을 개발, 테스트, 배포하는 데 필요한 도구를 제공합니다.

Xcode는 [Mac App Store](https://apps.apple.com/app/xcode/id497799835?ls=1&mt=12)에서 제공됩니다. 최신 베타 버전의 Xcode는 [developer website](https://developer.apple.com/download/)에서 제공됩니다.

Xcode Cloud 릴리스 정보는 [Xcode Cloud release notes](https://developer.apple.com/xcode-cloud/release-notes/)를 참고합니다.
