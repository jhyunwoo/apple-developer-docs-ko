# MapKit

앱 안에 지도 또는 위성 이미지를 표시하고, 관심 지점을 강조하여 보여 주며, 지도 좌표에 대한 플레이스마크 정보를 확인합니다.

## 개요

MapKit을 사용하면 지도와 위치 정보를 통해 앱에 장소성을 부여할 수 있습니다. MapKit 프레임워크를 사용하면 다음을 수행할 수 있습니다:

- 앱의 윈도우와 뷰 안에 지도를 직접 포함합니다.
- 지도에 주석과 오버레이를 추가해 관심 지점을 강조합니다.
- Look Around 기능을 추가해 사용자가 거리 수준에서 위치를 둘러볼 수 있게 합니다.
- 잘 알려진 관심 지점, 지리적 특징, 경계와의 사용자 상호작용에 대응합니다.
- 사용자가 목적지나 관심 지점을 쉽게 검색할 수 있도록 텍스트 완성을 제공합니다.

## MapKit API
- [AppKit 및 UIKit용 MapKit](https://developer.apple.com/documentation/mapkit/mapkit-for-appkit-and-uikit)
- [SwiftUI용 MapKit](https://developer.apple.com/documentation/mapkit/mapkit-for-swiftui): MapKit for SwiftUI를 사용하면 Apple 플랫폼 전반에서 지도 중심의 뷰와 앱을 구축할 수 있습니다. ViewBuilder와 view modifier를 사용해 뷰를 조합함으로써 적은 코드로도 표현력이 풍부하고 상호작용이 뛰어난 지도를 설계할 수 있습니다.
- [통합 Maps URL 채택하기](https://developer.apple.com/documentation/mapkit/unified-map-urls): Apple 플랫폼 전반에서 Maps 정보를 표시하기 위한 URL과 옵션에 접근합니다.
