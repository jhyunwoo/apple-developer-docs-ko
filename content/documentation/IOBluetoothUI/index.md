# IOBluetooth UI

사용자가 자신의 기기를 다른 Bluetooth 기기와 페어링할 수 있는 인터페이스를 제공합니다.

## 개요

BluetoothUI 프레임워크는 사용자가 Bluetooth 서비스를 선택할 수 있게 하는 인터페이스를 제공합니다.
