# Objective-C Runtime

Objective-C runtime과 Objective-C 루트 타입에 대한 저수준 접근을 얻습니다.

## 개요

[Objective-C Runtime](https://developer.apple.com/documentation/objectivec) 모듈 API는 Objective-C 언어의 기반을 정의합니다. 이 API에는 다음이 포함됩니다.

- 대부분의 Objective-C 클래스에 대한 루트 기능을 제공하는 [NSObject](https://developer.apple.com/documentation/objectivec/nsobject-swift.class) 클래스와 [NSObjectProtocol](https://developer.apple.com/documentation/objectivec/nsobjectprotocol) 프로토콜 같은 타입
- Objective-C 언어의 동적 특성을 지원하는 Objective-C runtime을 구성하는 함수와 데이터 구조

일반적으로 이 모듈을 직접 사용할 필요는 없습니다.

:::topic-grid
## 클래스
- [NSObject](https://developer.apple.com/documentation/objectivec/nsobject-swift.class): 대부분의 Objective-C 클래스 계층 구조의 루트 클래스이며, 서브클래스는 runtime 시스템에 대한 기본 인터페이스와 Objective-C 객체처럼 동작할 수 있는 기능을 상속받습니다.
- [Protocol](https://developer.apple.com/documentation/objectivec/protocol)
:::

:::topic-grid
## 프로토콜
- [NSObjectProtocol](https://developer.apple.com/documentation/objectivec/nsobjectprotocol): 모든 Objective-C 객체에 기본이 되는 메서드 집합입니다.
:::
