# visionOS Release Notes

visionOS SDK의 변경 사항을 알아봅니다.

## 개요

Apple Developer Program은 App Store에서 앱을 빌드하고 배포하는 데 필요한 모든 것을 제공합니다. 멤버십에는 베타 OS 릴리스, 고급 앱 기능, 그리고 앱과 Safari 확장을 개발, 테스트, 배포하는 도구에 대한 접근이 포함됩니다. 자세한 내용은 [Apple Developer Program](https://developer.apple.com/programs/)을 참고하세요.

### 버그 보고

릴리스 노트에 언급되지 않은 문제는 [Feedback Assistant](https://developer.apple.com/bug-reporting/)를 통해 버그를 보고하세요.
