# Technology Overviews

Apple 플랫폼용 소프트웨어를 개발할 때 사용하는 폭넓은 기술을 알아봅니다.

## 개요

Apple 플랫폼이 처음이든 여러 해 동안 사용해 왔든, 필요한 기술을 찾는 일은 중요한 첫 단계입니다. 사용할 수 있는 기술이 매우 많기 때문에 어디서 시작해야 할지 알기 어려울 때가 있습니다. 다음 주제는 사용할 수 있는 기술을 높은 수준에서 살펴볼 수 있게 하고, 특정 문제를 해결하기 위해 어떤 기술을 선택할 수 있는지에 대한 가이드를 제공합니다.

## 시작하기

앱이나 게임을 만들 때 사용하는 기반 기술부터 탐색을 시작하고, Liquid Glass를 채택해 인터페이스를 더욱 돋보이게 만드십시오.

## Apple 기술 살펴보기

앱의 고유한 경험을 만드는 데 사용하는 기술을 살펴보십시오. 앱의 데이터 모델 같은 핵심 기능을 만들거나, 기기별 하드웨어에 접근하거나, 앱을 더 지능적으로 만들거나, Apple 기기 고유의 기능을 채택하는 등 어떤 경우든 Apple 프레임워크는 이를 쉽고 효율적으로 수행하도록 도와줍니다.

## Apple Developer Documentation 탐색하기

개별 기술에 대한 심층 정보는 [Apple Developer Documentation](https://developer.apple.com/documentation/)을 참고하십시오. 개발자 문서에는 특정 기술 사용 방법을 배우는 데 도움이 되는 API reference, article, sample code, tutorial이 포함되어 있습니다. 또한 구체적인 문제를 해결하는 최선의 방법에 대한 가이드도 제공합니다.

:::topic-grid
## 시작하기
- [App design and UI](https://developer.apple.com/documentation/technologyoverviews/app-design-and-ui): 앱을 빌드하기 위한 프로그래밍 접근 방식을 선택하고, 앱 인터페이스를 만들고, 앱에 필요한 기본 동작을 구현합니다.
- [Games](https://developer.apple.com/documentation/technologyoverviews/games): Apple 하드웨어, 그래픽, 오디오, 소셜 게임 기능, 배포 도구를 사용해 전 세계 수백만 플레이어에게 훌륭한 게임 경험을 제공합니다.
:::

:::topic-grid
## Apple 기술 살펴보기
- [Data management](https://developer.apple.com/documentation/technologyoverviews/data-management): 앱의 데이터 모델을 구축하고, 데이터를 디스크나 iCloud에 영속화하며, 사용자의 개인 데이터에 접근합니다.
- [Core experiences](https://developer.apple.com/documentation/technologyoverviews/core-experiences): Apple 기기에서 앱 경험을 향상시키는 기능을 채택합니다.
- [Apple Intelligence and machine learning](https://developer.apple.com/documentation/technologyoverviews/ai-machine-learning): Apple Intelligence, 머신 러닝 및 관련 기술로 지능형 기능을 추가합니다.
- [Audio and video](https://developer.apple.com/documentation/technologyoverviews/audio-and-video): 앱에서 오디오와 비디오 콘텐츠를 지원합니다.
- [Hardware, networking, and sensors](https://developer.apple.com/documentation/technologyoverviews/hardware-networking-sensors): 기기 관련 sensor에 접근하고, 네트워크에 연결하며, 사용자 정의 하드웨어를 지원하는 저수준 driver와 소프트웨어를 빌드합니다.
:::
