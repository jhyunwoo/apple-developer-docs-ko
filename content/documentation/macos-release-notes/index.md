# macOS Release Notes

macOS SDK의 변경 사항을 알아봅니다.

## 개요

릴리스 노트는 최근 소프트웨어 릴리스에 대한 API 변경 사항, 알려진 문제, 수정 사항, 우회 방법, 지원 중단 항목의 세부 정보를 제공합니다.

### 버그 보고

릴리스 노트에 언급되지 않은 문제는 [Feedback Assistant](applefeedback://)를 통해 피드백을 보내십시오.

보고서를 작성할 때 제목과 설명에 전체 버전 번호를 포함해 주십시오. 예를 들면 "14 (23A_xxxx_)"와 같은 형식입니다. 전체 버전 번호는 이 Mac에 관하여 > macOS에서 확인할 수 있으며, 이를 클릭하면 확장된 버전 번호를 볼 수 있습니다. 자세한 내용은 [Bug Reporting](https://developer.apple.com/bug-reporting/)을 참고하십시오.
