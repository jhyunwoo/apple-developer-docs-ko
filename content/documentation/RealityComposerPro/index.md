# Reality Composer Pro

RealityKit 앱을 위한 3D 콘텐츠를 구축하고, 만들고, 설계합니다.

## 개요

Reality Composer Pro는 RealityKit 앱용 대화형 3D 콘텐츠를 구축할 때 사용할 수 있는 도구와 편집기 모음을 제공합니다. Reality Composer Pro를 사용하면 오디오 파일, 3D 모델, 파티클 효과, 조명, 애니메이션을 포함한 여러 asset으로 구성된 복잡한 scene을 만들 수 있습니다.

![Reality Composer Pro 프로젝트 창의 스크린샷입니다. 창 상단에는 Scene이라는 단일 탭이 있고, 창은 가로로 두 영역으로 나뉩니다. 위쪽 영역에는 scene 콘텐츠 navigator, 가운데 beach 3D 모델과 추가 asset을 보여 주는 viewport, 오른쪽 inspector가 있습니다. 아래쪽 영역에는 Project Browser, Shader Graph, Timelines Audio Mixer, Statistics 탭이 있고, 선택된 Project Browser는 왼쪽 hierarchy, 가운데 아이콘 그리드, 오른쪽 inspector로 나뉘어 선택한 asset의 entity hierarchy를 보여 줍니다.](https://developer.apple.com)

Reality Composer Pro에는 프로젝트 안에서 asset을 가져오고 관리하고, Shader Graph로 복잡한 재질을 설계하고, 애니메이션을 만들고, 콘텐츠 성능을 최적화하는 데 도움을 주는 여러 편집기도 포함되어 있습니다.
