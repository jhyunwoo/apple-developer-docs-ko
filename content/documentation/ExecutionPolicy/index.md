# Execution Policy

개발 도구가 실행 정책 예외를 관리할 수 있도록 기능을 제공합니다.

## 개요

이 프레임워크는 개발 도구가 로컬에서 빌드한 소프트웨어에 대한 실행 정책 예외를 관리할 수 있는 기능을 제공합니다.
