# Quartz

슬라이드쇼와 Core Image 필터를 사용해 사용자가 이미지를 탐색하고, 편집하고, 저장할 수 있게 합니다.

## 개요

이 문서 모음은 Quartz 프레임워크, 특히 Quartz Composer, ImageKit, PDFKit에 대한 API 레퍼런스를 제공합니다. Quartz Composer API는 그래픽 데이터를 처리하고 렌더링하는 기능을 지원하며, 개발자가 Quartz Composer 개발자 도구를 위한 사용자 정의 patch를 만들 수 있게 합니다. ImageKit은 이미지 탐색, 편집, 저장, 슬라이드쇼 표시, Core Image 필터 탐색 및 미리보기를 위한 사용자 인터페이스 지원을 제공합니다. PDFKit은 애플리케이션이 PDF 문서를 표시하고 조작할 수 있게 하는 기술입니다.
