# CoreAudioKit

오디오 유닛에 사용자 인터페이스를 추가합니다.

## 개요

Core Audio Kit는 Audio Unit 사용자 인터페이스를 빌드할 때 사용할 뷰와 컨트롤러를 제공합니다.

:::topic-grid
## Audio Units
- [AUViewController](https://developer.apple.com/documentation/coreaudiokit/auviewcontroller): 오디오 유닛용 사용자 정의 인터페이스를 만들 때 확장하는 기반 클래스입니다.
- [AUAudioUnitViewConfiguration](https://developer.apple.com/documentation/coreaudiokit/auaudiounitviewconfiguration): 오디오 유닛 사용자 인터페이스를 표시하는 방식을 설명하는 구성 객체입니다.
- [AUGenericView](https://developer.apple.com/documentation/coreaudiokit/augenericview): Cocoa 오디오 유닛을 위한 일반적인 사용자 인터페이스를 제공하는 뷰입니다.
- [AUPannerView](https://developer.apple.com/documentation/coreaudiokit/aupannerview): Cocoa 기반 panner 오디오 유닛을 위한 특화된 사용자 인터페이스를 제공하는 뷰입니다.
- [AUCustomViewPersistentData](https://developer.apple.com/documentation/coreaudiokit/aucustomviewpersistentdata): Audio Unit host가 뷰 데이터를 관리하기 위해 호출하는 메서드를 정의하는 프로토콜입니다.
:::

:::topic-grid
## Bluetooth 기기
- [CABTLEMIDIWindowController](https://developer.apple.com/documentation/coreaudiokit/cabtlemidiwindowcontroller): 근처의 Bluetooth 기반 MIDI 주변 기기를 표시하는 window controller입니다.
- [CABTMIDICentralViewController](https://developer.apple.com/documentation/coreaudiokit/cabtmidicentralviewcontroller): 근처의 Bluetooth 기반 MIDI 주변 기기를 표시하는 view controller입니다.
- [CABTMIDILocalPeripheralViewController](https://developer.apple.com/documentation/coreaudiokit/cabtmidilocalperipheralviewcontroller): iOS 기기를 Bluetooth 기반 MIDI 주변 기기로 광고하는 view controller입니다.
:::

:::topic-grid
## 네트워크 기기
- [CANetworkBrowserWindowController](https://developer.apple.com/documentation/coreaudiokit/canetworkbrowserwindowcontroller): 사용 가능한 네트워크 오디오 기기를 표시하는 window controller입니다.
:::

:::topic-grid
## 기기 간 오디오
- [CAInterDeviceAudioViewController](https://developer.apple.com/documentation/coreaudiokit/cainterdeviceaudioviewcontroller): 기기 간 오디오를 지원하는 iOS 기기를 표시하는 view controller 객체입니다.
:::

:::topic-grid
## 앱 간 오디오
- [CAInterAppAudioSwitcherView](https://developer.apple.com/documentation/coreaudiokit/cainterappaudioswitcherview): 오디오 스위처 사용자 인터페이스를 제공하는 뷰입니다.
- [CAInterAppAudioTransportView](https://developer.apple.com/documentation/coreaudiokit/cainterappaudiotransportview): 오디오 전송 사용자 인터페이스를 제공하는 뷰입니다.
:::
