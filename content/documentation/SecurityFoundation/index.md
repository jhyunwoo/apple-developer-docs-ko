# Security Foundation

Mac 앱 또는 데몬의 특정 기능에 대한 사용자의 접근을 제한합니다.

## 개요

이 문서의 이전 제목은 *Authorization Services Objective-C Reference*였으며, *Security Objective-C API* 문서의 `SFAuthorization` 장을 대체했습니다. 해당 문서의 다른 장들은 [Security Interface](https://developer.apple.com/documentation/SecurityInterface)로 대체되었습니다.

Security Foundation 프레임워크에는 단 하나의 클래스인 [SFAuthorization](https://developer.apple.com/documentation/securityfoundation/sfauthorization)이 포함되어 있으며, 이를 통해 Mac 앱 또는 데몬의 특정 기능에 대한 사용자의 접근을 제한할 수 있습니다.

:::topic-grid
## 클래스
- [SFAuthorization](https://developer.apple.com/documentation/securityfoundation/sfauthorization): Mac 앱 또는 데몬의 특정 기능에 대한 사용자의 접근을 제한할 수 있게 해 주는 클래스입니다.
:::
