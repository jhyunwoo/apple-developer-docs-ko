# Xcode

Apple의 통합 개발 환경으로 앱을 빌드하고, 테스트하고, 제출합니다.

## 개요

Xcode는 Apple 플랫폼용 앱을 빌드할 때 사용하는 도구 모음입니다. 앱 생성부터 테스트, 최적화, App Store 제출까지 전체 개발 워크플로를 Xcode로 관리할 수 있습니다.

![SwiftUI 미리보기와 iPhone 기기에서 앱을 실행하는 화면을 보여 주는 Xcode가 MacBook Pro에서 실행 중인 스크린샷입니다.](https://developer.apple.com)

Xcode에는 코드 완성, 소스 제어, 강력한 디버거를 갖춘 최고 수준의 소스 편집기가 포함되어 있습니다. 코딩 인텔리전스를 사용해 코드를 설명하고 작성하고, 버그를 분석하고, 수정 사항을 생성할 수 있습니다. 코드 조각을 실행하기 위해 playground macro를 추가하고, SwiftUI 미리보기를 추가해 UI를 빌드하는 동안 바로 확인할 수 있습니다.

Xcode에는 앱을 빠르게 개발하고 테스트하는 데 도움이 되는 여러 도구도 포함되어 있습니다.

- 실제 기기를 사용하지 않고 Simulator에서 전체 앱을 실행합니다.
- Icon Composer 앱을 사용해 앱용 단일 다층 아이콘을 만듭니다.
- Instruments를 사용해 앱을 프로파일링하고 분석하고, 성능을 개선하며, 시스템 리소스 사용량을 조사합니다.
- Reality Composer로 3D 콘텐츠를 구성합니다.
- Create ML로 사용자 정의 머신 러닝 모델을 학습시킵니다.
- Accessibility Inspector로 앱에서 접근성이 부족한 영역을 식별합니다.

:::note Note
[Mac App Store](https://apps.apple.com/us/app/xcode/id497799835)에서 최신 버전의 Xcode를 다운로드합니다. 베타 버전의 Xcode는 [Apple Developer website](https://developer.apple.com/xcode/)에서 다운로드합니다.
:::

## 핵심 항목
- [Creating an Xcode project for an app](https://developer.apple.com/documentation/xcode/creating-an-xcode-project-for-an-app): 템플릿에서 Xcode 프로젝트를 생성해 앱 개발을 시작합니다.
- [Creating your app’s interface with SwiftUI](https://developer.apple.com/documentation/xcode/creating-your-app-s-interface-with-swiftui): 코드와 레이아웃을 동기화하는 인터랙티브 미리보기와 함께 SwiftUI로 앱을 개발합니다.
- [Previewing your app’s interface in Xcode](https://developer.apple.com/documentation/xcode/previewing-your-apps-interface-in-xcode): 다양한 Apple 기기에서 앱 화면을 미리 보며 디자인을 빠르게 반복합니다.
- [Building and running an app](https://developer.apple.com/documentation/xcode/building-and-running-an-app): 소스 파일을 컴파일하고 앱 번들을 조립해 기기나 시뮬레이터에서 실행합니다.
- [Xcode updates](https://developer.apple.com/documentation/Updates/Xcode): Xcode의 중요한 변경 사항을 알아봅니다.
:::

## Xcode IDE
- [Projects and workspaces](https://developer.apple.com/documentation/xcode/projects-and-workspaces): Apple 플랫폼용 앱, 라이브러리, 기타 소프트웨어를 빌드하는 데 사용하는 코드와 리소스를 관리합니다.
- [Source control management](https://developer.apple.com/documentation/xcode/source-control-management): Xcode의 Git 소스 제어 지원으로 파일을 백업하고, 다른 사람과 협업하고, 릴리스를 태그합니다.
- [Capabilities](https://developer.apple.com/documentation/xcode/capabilities): In-App Purchase, Push Notifications, Apple Pay, iCloud 등 Apple이 제공하는 서비스를 활성화합니다.
- [Build system](https://developer.apple.com/documentation/xcode/build-system): 코드를 바이너리 형식으로 컴파일하고, 코드를 빌드하기 위한 프로젝트 설정을 사용자화합니다.
- [Command-line tools](https://developer.apple.com/documentation/xcode/command-line-tools): Terminal에서 프로젝트를 개발하고 사용자화합니다.
:::

:::topic-grid
## 코드
- [Source editor](https://developer.apple.com/documentation/xcode/source-editor): 소스 편집기를 사용해 소스 파일을 편집하고, 문제를 찾고, 필요한 변경을 수행합니다.
- [Bundles and frameworks](https://developer.apple.com/documentation/xcode/bundles-and-frameworks): 번들과 프레임워크 안에서 코드와 리소스를 구성합니다.
- [Swift packages](https://developer.apple.com/documentation/xcode/swift-packages): 재사용 가능한 코드를 만들고, 가볍게 구성하며, Xcode 프로젝트 전반과 다른 개발자와 공유합니다.
:::

:::topic-grid
## 인터페이스
- [Asset management](https://developer.apple.com/documentation/xcode/asset-management): 앱 아이콘, 이미지, 문자열, 데이터 파일, 머신 러닝 모델 및 기타 리소스를 프로젝트에 추가하고, 런타임에 이를 로드하는 방식을 관리합니다.
- [Localization](https://developer.apple.com/documentation/xcode/localization): 여러 언어와 지역을 지원해 앱의 시장을 확장합니다.
- [Accessibility Inspector](https://developer.apple.com/documentation/Accessibility/accessibility-inspector): 접근성 기능을 사용하는 사람들에게 앱이 자신을 어떻게 표현하는지 보여 줍니다.
:::

:::topic-grid
## 문서화

## 튜닝 및 디버깅
- [Devices and Simulator](https://developer.apple.com/documentation/xcode/devices-and-simulator): Mac에 연결된 기기나 Simulator의 기기를 구성하고 관리하며, 이를 사용해 앱을 실행합니다.
- [Debugging](https://developer.apple.com/documentation/xcode/debugging): Xcode 디버거, Xcode Organizer, Metal debugger, Instruments를 사용해 앱의 문제를 식별하고 해결합니다.
- [Performance and metrics](https://developer.apple.com/documentation/xcode/performance-and-metrics): Instruments와 Xcode Organizer를 사용해 시스템 리소스 사용량과 성능에 영향을 주는 문제를 측정하고 조사하고 해결합니다.
- [Testing](https://developer.apple.com/documentation/xcode/testing): 로직 실패, UI 문제, 성능 회귀를 찾아내기 위한 테스트를 개발하고 실행합니다.
:::

:::topic-grid
## 배포 및 지속적 통합
- [Distribution](https://developer.apple.com/documentation/xcode/distribution): 앱을 준비하고 팀, 베타 테스터, 고객과 공유합니다.
- [Xcode Cloud](https://developer.apple.com/documentation/xcode/xcode-cloud): Xcode Cloud로 앱을 자동으로 빌드, 테스트, 배포해 변경 사항을 검증하고 고품질 앱을 만듭니다.
:::
