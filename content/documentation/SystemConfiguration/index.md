# System Configuration

앱이 기기의 네트워크 구성 설정에 접근할 수 있게 합니다. Wi-Fi 또는 셀룰러 연결이 활성 상태인지와 같은 기기의 도달 가능성을 판단합니다.

## 개요

이 문서 모음은 System Configuration 프레임워크의 프로그래밍 인터페이스를 설명합니다. System Configuration 프레임워크는 대상 호스트의 도달 가능성을 동기 방식과 비동기 방식 모두로 판단하는 함수를 제공합니다. 또한 오류 감지 기능도 제공합니다.
