# File Provider UI

문서 브라우저의 컨텍스트 메뉴에 동작을 추가합니다.

## 개요

File Provider UI 확장을 사용하여 File Provider 확장에 사용자 정의 동작을 추가하세요. 이러한 동작은 사용자가 파일 제공자의 콘텐츠를 탐색하는 동안 항목을 길게 누르면 나타납니다. 사용자가 해당 동작을 선택하면 시스템이 사용자 정의 인터페이스를 표시하고, 그 안에서 사용자가 동작을 완료합니다. 사용자가 작업을 마친 뒤에는 반드시 동작을 명시적으로 취소하거나 완료해야 합니다.

File Provider 확장에 대한 자세한 내용은 [File Provider](https://developer.apple.com/documentation/FileProvider)를 참고하세요.

확장 생성에 대한 자세한 내용은 [App Extension Programming Guide](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/index.html#//apple_ref/doc/uid/TP40014214)를 참고하세요.

:::topic-grid
## 문서 브라우저 사용자화
- [Adding Actions to the Context Menu](https://developer.apple.com/documentation/fileproviderui/adding-actions-to-the-context-menu): 시스템 파일 브라우저에서 File Provider 확장의 사용자 정의 동작을 표시합니다.
- [FPUIActionExtensionViewController](https://developer.apple.com/documentation/fileproviderui/fpuiactionextensionviewcontroller): 선택한 동작을 수행하는 데 사용하는 사용자 정의 인터페이스입니다.
:::

:::topic-grid
## 오류
- [FPUIExtensionErrorCode](https://developer.apple.com/documentation/fileproviderui/fpuiextensionerrorcode): File Provider UI 확장에서 발생하는 오류의 오류 코드입니다.
- [FPUIErrorDomain](https://developer.apple.com/documentation/fileproviderui/fpuierrordomain): File Provider UI 확장에서 발생하는 오류의 오류 도메인입니다.
