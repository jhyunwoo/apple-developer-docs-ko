# Bundle Resources

앱, 프레임워크 또는 플러그인 번들 안에 있는 리소스입니다.

## 개요

*번들*은 실행 가능한 코드와 그 코드가 사용하는 리소스를 담고 있는 표준화된 계층 구조의 디렉터리입니다. 번들에는 이미지, 오디오 파일, 사용자 인터페이스 파일, 프로퍼티 리스트처럼 실행 시 접근할 수 있는 리소스가 들어 있습니다.

:::topic-grid
## 프로퍼티 리스트
- [Entitlements](https://developer.apple.com/documentation/bundleresources/entitlements): 실행 파일이 서비스나 기술을 사용할 수 있도록 권한을 부여하는 키-값 쌍입니다.
- [Information Property List](https://developer.apple.com/documentation/bundleresources/information-property-list): 번들을 식별하고 구성하는 키-값 쌍을 포함하는 리소스입니다.
- [Privacy manifest files](https://developer.apple.com/documentation/bundleresources/privacy-manifest-files): 앱 또는 서드파티 SDK가 수집하는 데이터와 사용하는 required reasons API를 설명합니다.
:::

:::topic-grid
## 구조
- [Placing content in a bundle](https://developer.apple.com/documentation/bundleresources/placing-content-in-a-bundle): 콘텐츠 유형에 따라 올바른 위치에 번들 콘텐츠를 배치합니다.
:::

:::topic-grid
## 유니버설 링크 서비스
- [applinks](https://developer.apple.com/documentation/bundleresources/applinks): 유니버설 링크 서비스 정의의 루트 객체입니다.
:::
