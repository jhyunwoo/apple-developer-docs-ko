# Link Presentation

앱에서 rich link를 가져오고, 제공하고, 표시합니다.

## 개요

Link Presentation 프레임워크를 사용하면 콘텐츠가 풍부한 URL을 일관된 방식으로 표시할 수 있습니다. URL에서 metadata를 가져오고, 앱 내부에 rich link 콘텐츠를 표시하며, iOS의 share sheet 경험에 link metadata를 제공할 수 있습니다.

![LPLinkView가 지도 URL을 표시하는 다이어그램으로, 위쪽에는 지도 이미지가 있고 아래쪽에는 위치 이름과 주소가 표시됩니다.](https://developer.apple.com)

링크 표시 방법에 대한 자세한 내용은 WWDC 2019 세션 [262: Embedding and Sharing Visually Rich Links](https://developer.apple.com/videos/play/wwdc2019/262/)를 참고하십시오.
