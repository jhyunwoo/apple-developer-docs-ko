# Latent Semantic Mapping

텍스트와 기타 토큰 기반 콘텐츠를 개발자가 정의한 범주로 분류합니다.

## 개요

Latent Semantic Mapping 프레임워크는 잠재 의미 정보를 바탕으로 텍스트를 분류합니다. 이 API의 C 기반 함수는 언어에 독립적으로 설계되어 있으며 Unicode 기반으로 동작합니다.

다른 자연어 처리 기능은 [Natural Language](https://developer.apple.com/documentation/NaturalLanguage)를 참고하십시오.

:::topic-grid
## 텍스트 분류
- [LSMMap](https://developer.apple.com/documentation/latentsemanticmapping/lsmmap): 범주 집합과 관련 텍스트 사이의 map입니다.
- [LSMText](https://developer.apple.com/documentation/latentsemanticmapping/lsmtext): 입력 텍스트입니다.
- [LSMResult](https://developer.apple.com/documentation/latentsemanticmapping/lsmresult): map 조회 결과입니다.
:::

:::topic-grid
## 오류 처리
- [Error Codes](https://developer.apple.com/documentation/latentsemanticmapping/error-codes): Latent Semantic Mapping의 오류 코드입니다.
:::
