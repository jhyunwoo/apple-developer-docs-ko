# Media Accessibility

비디오와 오디오 콘텐츠에 대한 사람들의 시스템 전역 환경설정을 지원하여 앱의 미디어를 더 접근 가능하게 만듭니다.

## 개요

사용자는 손쉬운 사용 시스템 설정에서 비디오, 노래, 이미지 같은 미디어 콘텐츠에 대한 다양한 환경설정을 지정할 수 있습니다. 예를 들어 동영상을 볼 때 표시되는 자막의 모양을 사용자화할 수 있습니다. Media Accessibility 프레임워크는 미디어 콘텐츠에 대한 이러한 손쉬운 사용 설정 정보를 제공하므로, 앱 UI를 사용자의 환경설정에 맞게 조정할 수 있습니다.

:::topic-grid
## 기능
- [Captions](https://developer.apple.com/documentation/mediaaccessibility/captions): 앱의 미디어 파일에 대한 closed-caption 데이터 표시를 조정합니다.
- [Flashing lights](https://developer.apple.com/documentation/mediaaccessibility/flashing-lights): 미디어 콘텐츠의 깜박이는 빛을 감지하고 완화하며 사용자에게 알립니다.
- [Music Haptics](https://developer.apple.com/documentation/mediaaccessibility/music-haptics): 알려진 음악 트랙과 함께 햅틱 트랙을 재생합니다.
:::
