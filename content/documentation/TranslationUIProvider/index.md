# TranslationUIProvider

사용자가 선택한 텍스트 번역을 위한 UI를 제공합니다.

:::topic-grid
## 기초
- [Preparing your app to be the default translation app](https://developer.apple.com/documentation/translationuiprovider/preparing-your-app-to-be-the-default-translation-app): 사용자가 기기에서 앱을 기본 번역 앱으로 설정할 수 있도록 앱을 구성합니다.
:::

:::topic-grid
## 번역 앱 extension 생성
- [TranslationUIProviderContext](https://developer.apple.com/documentation/translationuiprovider/translationuiprovidercontext): host process와 서드파티 extension 구현 사이의 XPC 통신을 캡슐화하는 객체입니다.
- [TranslationUIProviderExtension](https://developer.apple.com/documentation/translationuiprovider/translationuiproviderextension): 텍스트 선택 view를 제공하기 위해 번역 앱이 구현하는 protocol입니다.
- [TranslationUIProviderExtensionScene](https://developer.apple.com/documentation/translationuiprovider/translationuiproviderextensionscene): 이 extension의 scene이 구현해야 하는 protocol입니다.
:::

:::topic-grid
## 구성 및 텍스트 선택
- [TranslationProviderUIExtensionConfiguration](https://developer.apple.com/documentation/translationuiprovider/translationprovideruiextensionconfiguration): 번역 UI provider extension의 configuration 객체 타입입니다.
- [TranslationUIProviderSelectedTextScene](https://developer.apple.com/documentation/translationuiprovider/translationuiproviderselectedtextscene): 이 extension이 제공하는 특정 app extension scene입니다.
:::
