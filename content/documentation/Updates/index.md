# Updates

주요 문서 업데이트와 WWDC 하이라이트를 확인하고, 시간에 따라 이어지는 프레임워크 릴리스 업데이트를 살펴보며, 최신 릴리스 노트로 바로 이동합니다.

:::topic-grid
## WWDC
- [WWDC25](https://developer.apple.com/documentation/updates/wwdc2025): WWDC25에서 소개된 새로운 기술의 하이라이트입니다.
- [WWDC24](https://developer.apple.com/documentation/updates/wwdc2024): WWDC24에서 소개된 새로운 기술의 하이라이트입니다.
- [WWDC23](https://developer.apple.com/documentation/updates/wwdc2023): WWDC23에서 소개된 새로운 기술의 하이라이트입니다.
- [WWDC22](https://developer.apple.com/documentation/updates/wwdc2022): WWDC22에서 소개된 새로운 기술의 하이라이트입니다.
- [WWDC21](https://developer.apple.com/documentation/updates/wwdc2021): WWDC21에서 소개된 새로운 기술의 하이라이트입니다.
:::
