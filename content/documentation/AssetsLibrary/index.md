# Assets Library

사용자의 미디어 라이브러리에 있는 자산에 접근합니다.

## 개요

Assets Library 프레임워크를 사용해 Photos 애플리케이션이 관리하는 사진과 비디오에 접근합니다.

:::important Important
Assets Library 프레임워크는 iOS 9.0부터 deprecated되었습니다. 대신 [PhotoKit](https://developer.apple.com/documentation/PhotoKit) 프레임워크를 사용하세요. PhotoKit는 iOS 8.0 이상에서 사용자의 사진 라이브러리를 다룰 때 더 많은 기능과 더 나은 성능을 제공합니다.
:::

:::topic-grid
## 클래스
- [ALAsset](https://developer.apple.com/documentation/assetslibrary/alasset): Photo 애플리케이션이 관리하는 사진 또는 비디오를 나타내는 객체입니다.
- [ALAssetRepresentation](https://developer.apple.com/documentation/assetslibrary/alassetrepresentation): 주어진 객체의 표현 중 하나를 캡슐화하는 객체입니다.
- [ALAssetsFilter](https://developer.apple.com/documentation/assetslibrary/alassetsfilter): 그룹에서 자산을 가져올 때 사용할 필터링 기준을 캡슐화합니다.
- [ALAssetsGroup](https://developer.apple.com/documentation/assetslibrary/alassetsgroup): Photos 애플리케이션이 관리하는 자산의 순서 있는 집합을 나타내는 객체입니다. 요소의 순서는 사용자가 Photos 애플리케이션에서 보는 순서와 같습니다. 하나의 자산은 여러 자산 그룹에 속할 수 있습니다.
- [ALAssetsLibrary](https://developer.apple.com/documentation/assetslibrary/alassetslibrary): Photos 애플리케이션이 관리하는 비디오와 사진에 접근할 수 있게 해 주는 인스턴스입니다.
:::
