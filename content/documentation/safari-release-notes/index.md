# Safari Release Notes

iOS, iPadOS, macOS, visionOS의 Safari 및 Safari View Controller, iOS, iPadOS, macOS, watchOS, visionOS의 WKWebView, 그리고 macOS의 Web Inspector 변경 사항을 알아봅니다.

## 개요

Safari는 iOS와 macOS에서 사용할 수 있는 웹 브라우저 앱이자 웹 기술 플랫폼입니다. 웹 표준을 구현하는 빠른 오픈 소스 웹 렌더링 엔진 WebKit 위에 구축되어 있습니다. Safari에는 Intelligent Tracking Prevention, Reader mode, Safari App Extensions, Web Inspector 같은 Apple의 웹 혁신 기능이 포함되어 있습니다.
