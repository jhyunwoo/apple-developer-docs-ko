# PDFKit

앱에서 PDF 문서를 표시하고 조작합니다.

:::topic-grid
## 뷰
- [PDFView](https://developer.apple.com/documentation/pdfkit/pdfview): PDF Kit의 기능을 단일 위젯으로 캡슐화하여 Interface Builder를 통해 앱에 추가할 수 있게 하는 객체입니다.
- [PDFThumbnailView](https://developer.apple.com/documentation/pdfkit/pdfthumbnailview): PDF 문서의 페이지를 각각 나타내는 썸네일 집합을 포함하는 객체입니다.
:::

:::topic-grid
## 콘텐츠 모델
- [PDFDocument](https://developer.apple.com/documentation/pdfkit/pdfdocument): PDF 데이터 또는 PDF 파일을 나타내고, PDF 데이터를 기록, 검색, 선택하는 메서드를 정의하는 객체입니다.
- [PDFPage](https://developer.apple.com/documentation/pdfkit/pdfpage): `PDFPage`는 `PDFPage`의 하위 클래스이며, PDF 페이지를 렌더링하고 주석, 텍스트, 선택 영역을 다루는 메서드를 정의합니다.
- [PDFOutline](https://developer.apple.com/documentation/pdfkit/pdfoutline): `PDFOutline` 객체는 트리 구조 계층의 요소로, PDF 문서의 구조를 나타낼 수 있습니다.
- [PDFSelection](https://developer.apple.com/documentation/pdfkit/pdfselection): `PDFSelection` 객체는 PDF 문서에서 연속적이거나 비연속적인 텍스트 선택 영역을 식별합니다.
:::

:::topic-grid
## 주석
- [Adding Widgets to a PDF Document](https://developer.apple.com/documentation/pdfkit/adding-widgets-to-a-pdf-document): 텍스트, 버튼, 선택 위젯을 PDF 문서에 추가합니다.
- [Adding Custom Graphics to a PDF](https://developer.apple.com/documentation/pdfkit/adding-custom-graphics-to-a-pdf): 사용자 정의 주석과 페이지 그래픽을 생성하여 PDF 문서에 추가합니다.
- [Custom Graphics](https://developer.apple.com/documentation/pdfkit/custom-graphics): PDF 페이지에 워터마크를 추가하는 방법을 보여 줍니다.
- [PDF Widgets](https://developer.apple.com/documentation/pdfkit/pdf-widgets): PDF 문서에 위젯, 즉 상호 작용 가능한 폼 요소를 추가하는 방법을 보여 줍니다.
- [PDFAnnotation](https://developer.apple.com/documentation/pdfkit/pdfannotation): PDF 문서의 주석입니다.
:::
