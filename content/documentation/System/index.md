# System

타입 안전 API를 사용해 저수준 파일 작업을 수행합니다.

:::topic-grid
## System 채택하기
- [Adopting Swift File Operations](https://developer.apple.com/documentation/system/adopting-file-operations): System 모듈이 제공하는 파일 작업을 사용해 기존 C 코드를 Swift로 마이그레이션합니다.
- [Adopting Swift File Options](https://developer.apple.com/documentation/system/adopting-file-options): System 모듈이 제공하는 파일 작업 옵션을 사용해 기존 C 코드를 Swift로 마이그레이션합니다.
- [Adopting Swift Error Constants](https://developer.apple.com/documentation/system/adopting-errno): System 모듈이 제공하는 오류 상수를 사용해 기존 C 코드를 Swift로 마이그레이션합니다.
:::

:::topic-grid
## 파일
- [FileDescriptor](https://developer.apple.com/documentation/system/filedescriptor): 파일이나 socket처럼 입력 또는 출력 데이터 리소스를 가리키는 추상 핸들입니다.
- [FilePath](https://developer.apple.com/documentation/system/filepath): 파일 시스템의 위치를 나타냅니다.
- [FilePermissions](https://developer.apple.com/documentation/system/filepermissions): 파일의 접근 권한입니다.
:::

:::topic-grid
## 오류
- [Errno](https://developer.apple.com/documentation/system/errno): 어떤 종류의 오류가 발생했는지 시스템 호출이 전달할 때 사용하는 오류 번호입니다.
:::
