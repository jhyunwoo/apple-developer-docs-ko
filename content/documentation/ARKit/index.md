# ARKit

증강 현실 앱과 게임을 만들기 위해 하드웨어 센싱 기능을 통합합니다.

## 개요

*증강 현실* (AR)은 기기 센서의 라이브 뷰 위에 2D 또는 3D 요소를 더해, 그 요소가 실제 세계 안에 존재하는 것처럼 보이게 하는 사용자 경험을 말합니다. ARKit은 기기 모션 추적, 세계 추적, 장면 이해, 표시 편의 기능을 결합해 AR 경험 구축을 단순화합니다.

![로봇과 미래형 온실을 보여 주는 일러스트입니다.](https://developer.apple.com)

## visionOS
- [Setting up access to ARKit data](https://developer.apple.com/documentation/visionOS/setting-up-access-to-arkit-data): 앱이 ARKit을 사용할 수 있는지 확인하고 사용자의 개인 정보를 존중합니다.
- [ARKitSession](https://developer.apple.com/documentation/arkit/arkitsession): ARKit에서 데이터를 받기 위한 주 진입점입니다.
- [DataProvider](https://developer.apple.com/documentation/arkit/dataprovider): ARKit의 실시간 데이터 소스입니다.
- [Anchor](https://developer.apple.com/documentation/arkit/anchor): world space 안에서 객체의 정체성, 위치, 방향입니다.
- [ARKit in visionOS](https://developer.apple.com/documentation/arkit/arkit-in-visionos): 몰입형 증강 현실 경험을 만듭니다.
:::

:::topic-grid
## iOS
- [Verifying Device Support and User Permission](https://developer.apple.com/documentation/arkit/verifying-device-support-and-user-permission): 앱이 런타임에 ARKit을 사용할 수 있는지 확인하고 사용자 개인 정보를 존중합니다.
- [ARSession](https://developer.apple.com/documentation/arkit/arsession): 모션 추적, 카메라 passthrough, 이미지 분석 등 모든 AR 경험에 관련된 주요 작업을 관리하는 객체입니다.
- [ARAnchor](https://developer.apple.com/documentation/arkit/aranchor): 물리 환경에서 항목의 위치와 방향을 지정하는 객체입니다.
- [ARKit in iOS](https://developer.apple.com/documentation/arkit/arkit-in-ios): iOS 기기의 카메라와 모션 기능을 통합해 앱이나 게임에서 증강 현실 경험을 만듭니다.
:::
