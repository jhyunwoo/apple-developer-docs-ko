# WebKit

웹 콘텐츠를 앱에 자연스럽게 통합하고, 앱의 요구 사항에 맞게 콘텐츠 상호 작용을 사용자화합니다.

## 개요

WebKit 프레임워크를 사용하면 풍부하게 스타일링된 웹 콘텐츠를 앱의 네이티브 콘텐츠 안에 통합할 수 있습니다. WebKit은 플랫폼 네이티브 view와 함께 다음을 지원하여 콘텐츠에 완전한 브라우징 경험을 제공합니다.

- HTML, CSS, JavaScript를 사용한 풍부한 웹 콘텐츠 표시
- 페이지 콘텐츠의 점진적 로딩 처리
- 여러 MIME 타입과 복합 frame 요소 표시
- 콘텐츠 페이지 사이 탐색
- 최근 방문 페이지의 forward-back 목록 관리

WebKit에 대한 자세한 내용은 [https://webkit.org](https://webkit.org)를 참고하십시오.

:::topic-grid
## WebKit API
- [WebKit for AppKit and UIKit](https://developer.apple.com/documentation/webkit/webkit-for-appkit-and-uikit): AppKit 또는 UIKit 앱, 또는 Objective-C로 빌드한 앱에서 웹 콘텐츠를 표시합니다.
- [WebKit for SwiftUI](https://developer.apple.com/documentation/webkit/webkit-for-swiftui): 웹 페이지에 연결하는 새로운 표준 view를 사용해 SwiftUI 앱에 웹 콘텐츠를 통합합니다.
:::

:::topic-grid
## Safari 지원
- [Optimizing Your Website for Safari](https://developer.apple.com/documentation/webkit/optimizing-your-website-for-safari): Safari에 맞게 최적화하여 웹사이트를 개선합니다.
- [Delivering Video Content for Safari](https://developer.apple.com/documentation/webkit/delivering-video-content-for-safari): Safari에서 웹사이트의 비디오 성능과 표시 품질을 개선합니다.
- [Promoting Apps with Smart App Banners](https://developer.apple.com/documentation/webkit/promoting-apps-with-smart-app-banners): 웹사이트에서 App Store의 앱을 홍보하는 배너를 만듭니다.
:::

:::topic-grid
## WebDriver
- [macOS WebDriver Commands for Safari 11.1 and earlier](https://developer.apple.com/documentation/webkit/macos-webdriver-commands-for-safari-11-1-and-earlier): Safari 11.1 이하에서 지원하는 WebDriver 명령을 사용해 웹 콘텐츠를 테스트합니다.
- [macOS WebDriver Commands for Safari 12 and later](https://developer.apple.com/documentation/webkit/macos-webdriver-commands-for-safari-12-and-later): Safari 12 이상에서 지원하는 WebDriver 명령을 사용해 웹 콘텐츠를 테스트합니다.
- [About WebDriver for Safari](https://developer.apple.com/documentation/webkit/about-webdriver-for-safari): Safari의 WebDriver 확장을 사용해 웹 콘텐츠 테스트를 향상합니다.
- [Testing with WebDriver in Safari](https://developer.apple.com/documentation/webkit/testing-with-webdriver-in-safari): WebDriver를 활성화하고 테스트를 실행합니다.
