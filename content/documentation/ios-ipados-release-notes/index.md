# iOS & iPadOS Release Notes

iOS & iPadOS SDK의 변경 사항을 알아봅니다.

## 개요

릴리스 노트는 최근 소프트웨어 릴리스에 대한 API 변경 사항, 알려진 문제, 수정 사항, workaround, deprecation의 세부 정보를 제공합니다.

### 버그 보고

릴리스 노트에 언급되지 않은 문제는 [Feedback Assistant](applefeedback://)를 통해 피드백을 보내십시오.

보고서를 작성할 때는 제목과 설명에 전체 버전 번호를 포함하십시오. 예를 들면 `13 (17A_xxxx_)`와 같은 형식입니다. 전체 버전 번호는 설정 > 일반 > 정보 > 버전에서 확인할 수 있습니다. 자세한 내용은 [Bug Reporting](https://developer.apple.com/bug-reporting/)을 참고하십시오.
