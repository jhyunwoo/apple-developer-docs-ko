# 콘텐츠

:::topic-grid
## Topics
- [차트](https://developer.apple.com/kr/design/human-interface-guidelines/charts): 데이터를 차트로 정리하면 명확하고 시각적으로 돋보이게 정보를 전달할 수 있습니다.
- [이미지 보기](https://developer.apple.com/kr/design/human-interface-guidelines/image-views): 이미지 보기는 투명하거나 불투명한 배경에 단일 이미지 또는 경우에 따라 애니메이션이 적용된 이미지 시퀀스를 표시합니다.
- [텍스트 보기](https://developer.apple.com/kr/design/human-interface-guidelines/text-views): 텍스트 보기는 선택적으로 편집할 수 있는 여러 줄의 스타일이 지정된 텍스트 콘텐츠를 표시합니다.
- [웹 뷰](https://developer.apple.com/kr/design/human-interface-guidelines/web-views): 웹 뷰는 내장 HTML 및 웹사이트와 같은 풍부한 웹 콘텐츠를 앱에 직접 로드하고 표시합니다.
:::
