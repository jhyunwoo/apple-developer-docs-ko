# 차트 데이터

차트로 데이터를 표시하여 주목도를 높이고 명확하게 정보를 제공할 수 있습니다.

![데이터가 표시된 막대 차트의 스케치. 이미지에 직사각형 및 원형 그리드 선이 겹쳐져 있고, 여섯 가지 색상으로 된 기존 Apple 로고의 주황색을 은은하게 반영하는 주황색 색조가 적용됨.](https://developer.apple.com)

차트를 사용하면 사람들이 많은 텍스트를 읽고 해석하지 않아도 복잡한 정보를 효율적으로 파악할 수 있습니다. 차트는 그래픽적인 특성이 있으므로 사용자 경험을 특색 있게 표현하고 인터페이스에 시각적 흥미를 추가할 수 있는 더 많은 기회를 제공합니다. 차트를 생성하는 데 사용하는 구성요소에 관해 알아보려면 [차트](https://developer.apple.com/kr/design/human-interface-guidelines/charts)를 참조하십시오.

차트는 한번에 파악 가능한 정보를 제공하는 간단한 그래픽 차트부터 앱의 핵심 요소로서 다각적으로 데이터를 확인할 수 있는 풍부한 상호작용 경험을 제공하는 차트에 이르기까지 그 종류가 다양합니다. 차트의 종류에 상관없이 차트를 통해 사람들이 다음과 같은 중요한 데이터 기반 작업을 수행하도록 도울 수 있습니다.

- 과거 또는 예측 값을 기반으로 추세 분석하기
- 시간에 따라 변하는 프로세스, 시스템 또는 수량의 현재 상태를 시각화하기
- 여러 카테고리의 데이터를 비교하여 서로 다른 항목 또는 서로 다른 시간의 동일 항목을 평가하기

모든 데이터를 차트로 표시할 필요는 없습니다. 단순히 데이터만 제공하면 되고 데이터에 대한 정보를 전달하거나 데이터를 분석할 필요가 없다면 스크롤, 검색 및 정렬이 가능한 목록 또는 표로 데이터를 제공하는 것을 고려하십시오.

## 모범 사례

**데이터 세트의 중요 정보를 하이라이트하고 싶은 경우 차트를 사용하십시오.** 차트는 시각적으로 눈에 잘 띄기 때문에 사람들의 주목을 끕니다. 눈에 잘 띄는 이러한 특징을 활용하려면 사람들이 관심을 갖는 데이터에서 무엇을 확인할 수 있는지 명확하게 설명하십시오.

**차트를 간단하게 만들고 필요할 경우 세부사항을 추가로 선택할 수 있게 하십시오.** 차트에 가능한 많은 데이터를 채워 넣고 싶더라도 참아야 합니다. 데이터가 너무 많으면 차트가 시각적으로 과도한 느낌을 주고 사용하기 어려워 의도했던 대로 관계 및 기타 정보를 제공하기 어렵습니다. 표시할 데이터가 많거나 제공하려는 기능이 많다면 해당 정보를 점차적으로 확인할 수 있도록 지원해 보십시오. 예를 들어, 사람들이 자신의 관심에 따라 다양한 수준의 세부사항 또는 데이터의 일부를 볼 수 있게 지원할 수 있습니다. 사람들이 대화식 차트에 익숙해지도록 이전보다 더 많은 기능이 포함된 여러 버전의 차트를 점차적으로 제공할 수도 있습니다.

**앱의 모든 차트가 접근 가능하도록 하십시오.** 차트는 데이터의 그래픽 표시 및 시각적 설명을 통해 시각적으로 정보를 제공합니다. 시각적 설명을 표시하는 것 외에도 차트 값과 구성요소를 설명하는 손쉬운 사용 레이블 및 사람들이 차트와 상호작용하도록 돕는 손쉬운 사용 요소를 꼭 제공해야 합니다. 지침을 보려면 [차트](https://developer.apple.com/kr/design/human-interface-guidelines/charts#Enhancing-the-accessibility-of-a-chart)의 내용을 참조하십시오.

## 효과적인 차트 디자인하기

**일반적인 경우, 자주 쓰이는 차트 유형을 더 우선적으로 사용하십시오.** 사람들은 막대 차트, 선 차트와 같이 자주 쓰이는 차트 유형에 익숙하기 때문에 앱에서 이러한 유형의 차트를 사용하면 사람들이 차트를 읽는 방법을 이미 알고 있을 확률이 높습니다. 지침을 보려면 [차트](https://developer.apple.com/kr/design/human-interface-guidelines/charts)의 내용을 참조하십시오.

**새로운 방식으로 데이터를 표시하는 차트를 생성하는 경우, 차트를 해석하는 방법을 사람들에게 알려주십시오.** 예를 들어, Apple Watch가 iPhone과 페어링되면 ‘활동’ 앱은 개별적으로 애니메이션을 적용하여 활동 링을 소개하고 각각의 링이 움직이기, 운동하기, 일어서기 수치에 어떻게 매핑되는지 보여줍니다.

**여러 수준 또는 관점에서 데이터를 살펴보면서 어떤 세부사항을 표시하면 차트를 향상할 수 있을지 생각해 보십시오.** 예를 들어, 거시적 수준에서 데이터를 보면 합계 또는 평균과 같이 사람들이 관심을 가질 만한 상위 수준의 요약을 결정하는 데 도움이 됩니다. 중간 수준의 관점에서는 사람들이 데이터의 유용한 부분을 식별할 수 있도록 돕는 방법을 찾을 수 있으며, 개별 데이터 포인트를 살펴볼 때는 특정 값 또는 항목으로 사람들의 관심을 끄는 방법을 찾을 수 있습니다. 다양한 관점으로 차트를 바라볼 수 있는 정보를 표시하면 사람들이 차트를 더 적극적으로 사용하도록 유도할 수 있습니다.

**차트에 설명 텍스트를 추가하여 이해를 도우십시오.** 설명이 포함된 텍스트 제목, 부제목 및 주석을 사용하면 차트에서 가장 중요한 정보를 강조하고 실행 가능한 핵심 사항을 하이라이트할 수 있습니다. 또한 차트의 헤드라인 또는 요약 역할을 하는 간략한 설명 텍스트를 표시하여 사람들이 필수 정보를 한눈에 파악할 수 있도록 할 수 있습니다. 예를 들어, 날씨 앱은 ‘다음 1시간 동안 이슬비가 내릴 수 있음’과 같이 지금 사람들에게 필요한 정보를 요약한 텍스트를 향후 24시간 동안의 시간별 일기예보 스크롤 목록 위에 표시합니다. 설명 헤드라인 또는 요약이 차트의 접근성을 더 높여주기는 하지만 손쉬운 사용 레이블을 대신할 수는 없습니다.

**기능, 주제, 세부 정도에 맞춰 차트의 크기를 결정하십시오.** 일반적으로 차트는 세부사항을 문제없이 표시하고 상호작용을 제대로 지원하기에 충분한 크기여야 합니다. 예를 들어, 넓은 공간을 사용하여 사람들이 차트의 세부사항 및 설명 텍스트(레이블, 주석 등)를 항상 쉽게 읽고 차트의 범위를 변경하거나 다른 관점에서 데이터를 조사할 수 있도록 지원할 수 있습니다. 이와 반대로, 작은 차트를 사용하여 한눈에 알아볼 수 있는 개별 항목 정보를 제공하거나, 작은 차트를 큰 차트의 스냅샷 또는 미리보기로 사용하고 해당 차트를 다른 보기에 표시할 수 있도록 지원할 수 있습니다.

**여러 차트 간에 일관성을 유지하고, 차이점을 하이라이트하고 싶은 경우에만 다르게 표시하십시오.** 앱에 있는 여러 차트가 비슷한 역할을 하는 경우, 차트에 서로 다른 유형 또는 스타일을 적용하면 차트가 관련성이 없는 것처럼 보일 수 있으니 이를 피해야 합니다. 또한 앱의 차트에 일관된 시각적 방식을 적용하면 사람들이 한 차트에서 알게 된 사항을 바탕으로 다른 차트도 이해할 수 있게 됩니다. 차트 간의 유의미한 차이점을 하이라이트하려는 경우에는 차트 유형 및 스타일을 다르게 사용하는 것을 고려하십시오.

**동일한 데이터를 사용하는 여러 차트 간에 연속성을 유지하십시오.** 여러 차트를 사용하여 사람들이 다양한 관점에서 데이터 세트를 살펴볼 수 있도록 하는 경우, 하나의 차트 유형과 일관된 색상, 주석, 레이아웃 및 설명 텍스트를 사용하여 데이터 세트가 동일함을 나타내십시오. 예를 들어, 건강 추세 화면은 각각 특정 시각 스타일로 걸음 또는 휴식기 심박수와 같은 영역의 최근 추세를 나타내는 작은 차트를 표시합니다. 해당 영역의 데이터를 모두 표시하기 위해 차트를 선택하면 동일한 스타일, 색상, 마크 및 주석을 사용하는 확장된 버전의 차트가 나타나 버전 간에 관계가 있음을 알 수 있습니다.
