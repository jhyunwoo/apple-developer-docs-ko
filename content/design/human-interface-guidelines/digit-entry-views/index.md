# 숫자 입력 화면

숫자 입력 화면은 전체 화면을 채우며 사람들에게 숫자 전용 키보드를 사용하여 PIN과 같은 일련의 숫자를 입력하도록 요청합니다.

![스타일화된 Apple TV 5자리 암호 입력 화면 모양이 표시되어 있음. 여섯 가지 색상으로 된 기존 Apple 로고의 빨간색을 은은하게 반영하는 빨간색 색조가 이미지에 적용됨.](https://developer.apple.com)

숫자 줄 위에 선택적으로 제목과 프롬프트를 추가할 수 있습니다.

## 모범 사례

**안전한 숫자 필드를 사용하십시오.** 안전한 숫자 필드는 화면상에 입력된 숫자 대신 별표를 표시합니다. 앱에서 민감한 데이터를 요청하는 경우 항상 안전한 숫자 필드를 사용하십시오.

**숫자 입력 화면의 목적을 명확하게 설명하십시오.** 제목과 프롬프트를 사용하여 사람들이 숫자를 입력해야 하는 이유를 설명하십시오.

## 플랫폼 고려 사항

*iOS, iPadOS, macOS, visionOS 또는 watchOS에서는 지원되지 않습니다.*
